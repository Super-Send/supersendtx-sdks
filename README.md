# Ranla & SuperSend TX SDKs

Official thin HTTP clients for the [Ranla](https://ranla.ai) email API and the legacy [SuperSend TX](https://supersendtx.com) transactional API.

| Language | Ranla | SuperSend TX (legacy) |
|----------|-------|------------------------|
| Node | `npm install ranla` | `npm install supersendtx` |
| Python | [`ranla-python/`](./ranla-python) · `pip install ranla` | [`python/`](./python) · `pip install supersendtx` |
| Go | [`go/ranla/`](./go/ranla) · `go get github.com/Super-Send/supersendtx-sdks/go/ranla@v0.8.4` | [`go/`](./go) · `go get github.com/Super-Send/supersendtx-sdks/go@v0.8.4` |
| PHP | [`ranla-php/`](./ranla-php) · `composer require ranla/ranla` | [`php/`](./php) · `composer require supersendtx/supersendtx` |
| Symfony Mailer | — | [`symfony-mailer/`](./symfony-mailer) · `composer require supersendtx/symfony-mailer` |
| Laravel | — | [`laravel/`](./laravel) · `composer require supersendtx/laravel` |
| Ruby | [`ranla-ruby/`](./ranla-ruby) · `gem install ranla` | [`ruby/`](./ruby) · `gem install supersendtx` |

Docs: [docs.ranla.ai](https://docs.ranla.ai) · legacy [docs.supersendtx.com](https://docs.supersendtx.com)

## Development

SDK source is maintained by Super Send and mirrored to this repository on release.
Do not open PRs for API changes here — they are handled through our internal development process.
